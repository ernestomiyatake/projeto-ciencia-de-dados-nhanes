
# Projeto Prático de Ciência de Dados: Análise NHANES e Machine Learning

Este repositório contém o meu primeiro projeto prático completo de Ciência de Dados, desenvolvido como parte da consolidação dos estudos em Python, Pandas, Visualização de Dados e Machine Learning.

## 📊 Sobre o Projeto
O objetivo principal foi analisar dados de saúde (utilizando o dataset NHANES) para prever e entender padrões relacionados à saúde e biometria, passando por todas as etapas essenciais de um projeto de dados:
- Tratamento e manipulação de dados com **Pandas**.
- Geração de gráficos e análise exploratória para extração de insights.
- Construção e avaliação de modelos preditivos.

## 🤖 Modelagem Preditiva (Machine Learning)
No processo de modelagem, testei e comparei diferentes abordagens:
- **Árvore de Decisão Simples:** Serviu como baseline inicial para entender o comportamento dos dados.
- **Random Forest (Floresta Aleatória):** Superou o modelo simples, trazendo uma melhoria significativa e reduzindo o erro médio absoluto (MAE) de ~37.79 para ~31.48.

## 💡 Principais Conclusões e Próximos Passos
O projeto demonstrou o valor prático dos modelos para triagem em saúde pública e abriu caminho para futuras melhorias, como técnicas avançadas de *Feature Engineering* e otimização de hiperparâmetros (*Tuning*).
